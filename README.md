### 📂 Projets phares

#### 🎬 VIDSELLA — SaaS de création de vidéos publicitaires · [Démo](https://power-ads.vercel.app) · [Code](https://github.com/jeanbaptistejunioroth-jpg/power-ads)
`Next.js 15` `React 19` `TypeScript` `Supabase` `Tailwind CSS`

Plateforme où les e-commerçants commandent des vidéos pub pour leurs produits.
- Inscription en 3 étapes (code e-mail), connexion Google, espace client complet
- Import de produits depuis **Shopify**, script généré par **IA** puis validé par le client
- Paiement par tokens, **prix dans la monnaie du visiteur** (taux de change du jour)
- **8 langues** dont l'arabe (droite à gauche), mode clair / sombre, responsive
- Suivi des commandes et messagerie du service client **en temps réel**

#### 📄 CanalPDF — 34 outils PDF 100 % dans le navigateur · [Site](https://canalpdf.com) · [Vitrine](https://github.com/jeanbaptistejunioroth-jpg/canalpdf-showcase)
`JavaScript` `pdf-lib` `PDF.js` `Transformers.js` `Node.js` `PWA`

Application web de traitement PDF sans serveur : les fichiers ne quittent jamais l'appareil de l'utilisateur.
- **34 outils** : fusionner, compresser, convertir (Word, JPG, Excel, HTML), signer, OCR, protéger, comparer…
- **IA locale dans le navigateur** : traduction (OPUS-MT) et résumé de PDF
- **6 langues**, 214 pages générées par un générateur statique Node.js, SEO complet (JSON-LD, hreflang, sitemap)
- Sécurité : CSP stricte, code obfusqué et verrouillé sur le domaine, application installable (PWA)

#### ☀️ Supervision Solaire — Délestage intelligent d'une installation PV · [Démo](https://supervision-solaire-enspd.vercel.app) · [Code](https://github.com/jeanbaptistejunioroth-jpg/supervision-solaire-enspd)
`ESP32` `Arduino` `C++` `JavaScript` `Telegram Bot API`

Système IoT réalisé pour l'installation photovoltaïque du bloc administratif de l'ENSPD.
- Mesures temps réel : tension batterie, tension AC, courant (ACS712), puissance, état de charge
- **Délestage automatique à 3 niveaux** par priorité des charges, avec réarmement
- Tableau de bord web embarqué sur l'ESP32 + **alertes Telegram**

#### ⬇️ StreamLoader — Téléchargeur vidéo web + application Windows · [Code](https://github.com/jeanbaptistejunioroth-jpg/streamloader)
`Node.js` `Express` `SQLite` `Electron` `JWT` `Nginx`

- API REST Express, progression des téléchargements en **temps réel (Server-Sent Events)**
- Comptes, abonnement Premium, paiement avec **webhook signé HMAC-SHA256**, limitation de débit
- Bot Telegram, **application desktop Windows (Electron)** avec installeur, déploiement sur VPS (Nginx + PM2)
